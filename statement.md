# Project Statement

## Project Title

Smart Multi-Function Calculator

## Problem Statement

Basic calculators generally provide only arithmetic operations. Students learning programming also need to implement and understand mathematical algorithms such as prime checking, Armstrong number checking, factorial, GCD, LCM, and Fibonacci series.

The Smart Multi-Function Calculator provides these operations through a single modular Python application.

## Scope

The project covers:

* Basic arithmetic operations
* Multiple-number calculations
* Number analysis
* Mathematical algorithms
* Menu-driven interaction
* Input validation
* Modular Python functions
* Basic software testing

## Target Users

The primary target users are:

* Students learning Python
* Beginners practicing programming concepts
* Students requiring a basic mathematical utility
* Users who want multiple mathematical functions in one application

## High-Level Features

1. Addition of multiple numbers
2. Subtraction of multiple numbers
3. Multiplication of multiple numbers
4. Division of multiple numbers
5. Prime number checking
6. Armstrong number checking
7. Palindrome checking
8. Even/Odd checking
9. Perfect number checking
10. Factorial calculation
11. Power calculation
12. GCD calculation
13. LCM calculation
14. Fibonacci series generation
15. Error handling
16. Modular program structure
17. Automated basic testing
