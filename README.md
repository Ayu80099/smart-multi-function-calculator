# Smart Multi-Function Calculator

## 1. Project Overview

Smart Multi-Function Calculator is a modular Python-based calculator application that provides arithmetic operations, number analysis, and advanced mathematical functions.

The project is designed using separate Python modules and functions so that each operation can be developed, tested, and maintained independently.

## 2. Features

### Arithmetic Operations

* Addition of multiple numbers
* Subtraction of multiple numbers
* Multiplication of multiple numbers
* Division of multiple numbers
* Division-by-zero validation

### Number Analysis

* Prime number checker
* Armstrong number checker
* Palindrome checker
* Even/Odd checker
* Perfect number checker

### Advanced Mathematics

* Factorial
* Power calculation
* GCD
* LCM
* Fibonacci series

## 5. How to Run

Install Python 3 on your computer.

### Step 2: Clone the Repository

bash

### Step 3: Open the Project

Open the project folder in VS Code.

bash
